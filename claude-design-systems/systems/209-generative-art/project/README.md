This interface celebrates the beauty of procedural generation and algorithmic art - where mathematical elegance meets creative expression. Every visual element suggests it could be generated by code, from gradient patterns to geometric shapes. The design honors the creative coding movement (Processing, p5.js, generative design) while maintaining practical usability for digital products.

## Content fundamentals

- Write for members and staff of the organization: direct, professional but warm.
- Headings name the thing plainly: “ALGORITHMIC DESIGN”, “RECENT CREATIONS”, “Sunset Sequence”, “Recursive Hexagons”.
- Buttons are short verb phrases in Title Case: “◆ Generate”, “⚡ Quick Generate”, “Reset”.
- Navigation uses single nouns: “Generate”, “Algorithms”, “Patterns”, “Gallery”.
- The reference page uses emoji as inline glyphs (⚡ ⚠ ©); keep them functional, never decorative.

## Color

- Set the page on `page-bg` with body text in `page-text`. The theme is light.
- Identity colours: `color-deep-indigo`, `color-electric-pink`, `color-sunset-orange`, `color-golden-yellow`. Lead with the first; use the rest for accents and emphasis.
- Each token's note says where the reference page uses it and, for text colours, its contrast on `page-bg`. Keep body text at 4.5:1 or better.

## Typography

- `display` — "Space Mono", monospace
- `body` — "IBM Plex Sans", system-ui, -apple-system, sans-serif

Faces are hosted on Google Fonts (Space Mono, IBM Plex Sans); load them with:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Space+Mono:wght@400;700&family=IBM+Plex+Sans:wght@300;400;500;600&display=swap">
```

- Set titles in `display`, sections in `heading-2` and running text in `body`.
- Uppercase is reserved for small labels (`label`), always with the letter-spacing given.

### Type rationale

- Space Mono (Headings):
- Monospace suggesting code and algorithms
- Technical precision meeting creative expression
- Clear readability in generative contexts
- Developer aesthetic with artistic soul

- IBM Plex Sans (Body):
- Geometric forms echoing generative patterns
- Excellent readability for content
- Technical heritage with warm personality
- Neutral enough to let generative visuals shine
