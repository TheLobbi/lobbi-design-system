"Forward-Thinking Associations Harnessing AI and Data Science" Target Organizations: Design Intent: This style reimagines association management for the AI era. It combines the analytical rigor of think tank research with the futuristic aesthetics of quantum computing and holographic interfaces. The result is a platform that feels like mission control for intelligent organizations—where member insights are generated by ML models, engagement is predicted by algorithms, and community health is visualized through data-driven dashboards. ## Content fundamentals

- Write for members and staff of the organization: direct, formal and composed.
- Headings name the thing plainly: “Association Intelligence”, “Member Intelligence Hub”, “High-Value Predictions”, “Churn Risk Alerts”.
- Buttons are short verb phrases in Title Case: “Run Analysis”, “Export Results”.
- Navigation uses single nouns: “Dashboard”, “Analytics”, “Predictions”, “Models”.
- The reference page uses emoji as inline glyphs (🧠 🤖 📊 🎯 ⚡ ©); keep them functional, never decorative.

## Color

- Set the page on `page-bg` with body text in `page-text`. The theme is light.
- Identity colours: `tech-white`, `intelligence-blue`, `quantum-purple`, `hologram-cyan`. Lead with the first; use the rest for accents and emphasis.
- Status colours (`alert-amber`) always travel with a word or icon; never signal state by hue alone.
- Each token's note says where the reference page uses it and, for text colours, its contrast on `page-bg`. Keep body text at 4.5:1 or better.

### Palette rationale

- Blue (Primary): Intelligence, data, trust
- Purple (Accent): Quantum states, AI models, innovation
- Cyan (Highlight): Holographic glows, data points
- Green (Success): Model training, healthy metrics

## Typography

- `display` — Inter, -apple-system, sans-serif
- `body` — "JetBrains Mono", "Courier New", monospace

Faces are hosted on Google Fonts (Inter, JetBrains Mono); load them with:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400;500;600&display=swap">
```

- Set titles in `display`, sections in `heading-2` and running text in `body`.
- Uppercase is reserved for small labels (`heading-4`, `label`), always with the letter-spacing given.

## Spacing, shape and elevation

- Spacing steps: `space-1` 4px, `space-2` 8px, `space-3` 12px, `space-4` 16px, `space-5` 20px, `space-6` 24px, `space-7` 28px, `space-8` 32px. Pad cards and sections from these steps only.
- Corners: `radius-sm` 6px, `radius-md` 10px, `radius-lg` 14px.
- Elevation: `shadow-sm`, `shadow-md`, `shadow-lg`, `shadow-glow-cyan`, `shadow-glow-purple`, lowest first for resting cards, higher for hover and overlays.

- INTELLIGENCE DASHBOARD EFFICIENCY
- 16px base spacing unit (data dashboard standard)
- 20px card gaps (efficient but breathable)
- 32px section margins (analytical breathing room)
- Max-width: 1440px (wide dashboard layout)
- Moderate padding (function meets comfort)

## States and motion

Timing values: `--transition` 250ms cubic-bezier(0.4, 0, 0.2, 1).

- Honour `prefers-reduced-motion`: drop lifts and transitions to instant state changes.

## Iconography

- Inline SVG line icons on a 24×24 viewBox, 2px stroke, drawn in `currentColor` so they take the text colour around them.
- No logo ships with this style: set the organization name in the `display` style.

## Accessibility

- `page-text` on `page-bg` measures 17.1:1.
- Every interactive element shows a visible focus state at 3:1 or better against its surface.
- Measured on `page-bg`, these text colours fall short of 4.5:1: `hologram-cyan` 1.7:1, `slate-400` 2.5:1, `header-bg` 1.0:1. Use them only for large text (24px+) or on the fills their notes name, whatever the design notes below claim.
