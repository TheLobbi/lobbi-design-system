## Content fundamentals

- Write for members and staff of the organization: direct, formal and composed.
- Headings name the thing plainly: “QUANTUM COMPUTING INVESTMENT PLATFORM”, “INVESTMENT STRATEGIES”, “Multi-Asset Superposition”, “Institutional Fixed Income”.
- Buttons are short verb phrases in Title Case: “◆ Execute Quantum Analysis”, “⟨ψ⟩ Run Simulation”, “Reset Parameters”.
- Navigation uses single nouns: “Portfolio”, “Analytics”, “Trading”, “Research”.
- The reference page uses emoji as inline glyphs (⚡ ⚠ ©); keep them functional, never decorative.

## Color

## Typography

- `display` — "IBM Plex Serif", Georgia, serif
- `body` — "IBM Plex Mono", "Courier New", monospace

Faces are hosted on Google Fonts (IBM Plex Serif, IBM Plex Mono); load them with:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Serif:wght@300;400;500;600;700&family=IBM+Plex+Mono:wght@400;500;600&display=swap">
```

- Set titles in `display`, sections in `heading-2` and running text in `body`.
- Uppercase is reserved for small labels (`label`), always with the letter-spacing given.
