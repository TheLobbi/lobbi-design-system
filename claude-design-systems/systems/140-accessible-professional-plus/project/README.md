## Content fundamentals

- Write for members and staff of the organization: direct, formal and composed.
- Headings name the thing plainly: “Accessibility Impact Metrics”, “Accessibility Services”, “Accessibility Audits”, “Training & Education”.
- Buttons are short verb phrases in Title Case: “Request Audit”, “Learn More”, “View Courses”, “Schedule Training”.
- Navigation uses single nouns: “Home”, “Services”, “Resources”, “Compliance”, “Support”, “Contact”.
- The reference page uses emoji as inline glyphs (🔍 📚 ⚙ ©); keep them functional, never decorative.

## Color

- Set the page on `page-bg` with body text in `page-text`. The theme is light.
- Identity colours: `color-primary`, `color-primary-dark`. Lead with the first; use the rest for accents and emphasis.
- Status colours (`color-success`, `color-success-light`, `color-error`, `color-error-light`, `color-warning`, `color-warning-light`) always travel with a word or icon; never signal state by hue alone.
- Each token's note says where the reference page uses it and, for text colours, its contrast on `page-bg`. Keep body text at 4.5:1 or better.

## Typography

- `display` — "Atkinson Hyperlegible", Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif
- `inter` — "Inter", sans-serif

Faces are hosted on Google Fonts (Atkinson Hyperlegible, Inter); load them with:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Atkinson+Hyperlegible:wght@400;700&family=Inter:wght@400;500;600;700&display=swap">
```

- Set titles in `display`, sections in `heading-2` and running text in `body`.

## States and motion

- Progressive Enhancement:
- Core functionality works without JavaScript
- Enhanced interactions layer on top
- Keyboard-first design approach
- Mouse/touch as secondary modalities

- Focus Management:
- Skip link visible on first Tab press
- Focus order matches visual order
- Focus never hidden or trapped
- Focus outline: 3px solid #0064cc with 2px offset
- Focus visible on ALL interactive elements

- Feedback Loops:
- Immediate visual feedback on interaction
- Status changes announced to screen readers
- Loading states clearly communicated
- Error messages specific and actionable
- Success confirmations explicit

- Transition Speed:
- 0.2s for micro-interactions
- 0.3s for component transitions
- Respects prefers-reduced-motion
- No animation required for comprehension

- RESPONSIVE BEHAVIOR - Mobile Accessibility

- Breakpoint Strategy:
- Desktop (1200px+): Multi-column layouts
- Tablet (768px-1199px): Simplified grid
- Mobile (320px-767px): Single column, larger targets

- Mobile Enhancements:
- Touch targets increase to 56px on mobile
- Font sizes scale up slightly for small screens
- Reduced columns to prevent crowding
- Sticky header collapses to save space
- Forms stack vertically with full-width inputs

- Zoom Support:
- Layout maintains at 200% zoom
- No horizontal scrolling required
- Text reflows naturally
- Images scale proportionally

- PERFORMANCE CONSIDERATIONS

- Font preloading for faster render
- Minimal CSS (no framework bloat)
- No JavaScript required for core functionality
- Semantic HTML reduces markup size
- System font fallbacks ensure instant render
- Print-friendly styles included
