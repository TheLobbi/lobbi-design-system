## Content fundamentals

## Color

- Set the page on `page-bg` with body text in `page-text`. The theme is light.
- Identity colours: `color-teal`, `color-coral`, `color-purple`, `color-blue`. Lead with the first; use the rest for accents and emphasis.
- Status colours (`badge-success-bg`, `badge-warning-bg`, `badge-error-bg`) always travel with a word or icon; never signal state by hue alone.
- Each token's note says where the reference page uses it and, for text colours, its contrast on `page-bg`. Keep body text at 4.5:1 or better.

## Typography

- mathematical precision. The faceted aesthetic adds depth and dimension without
- requiring actual 3D rendering, using clever gradients and angular shapes to
- simulate crystalline surfaces.
