## Content fundamentals

- Write for members and staff of the organization: direct, relaxed and conversational.
- Headings name the thing plainly: “KAPOW! Metrics”, “POW! Services”, “Visual Storytelling”, “Video Production”.
- Buttons are short verb phrases in Title Case: “Get Started”, “View Portfolio”, “Start Project”, “Watch Reels”.
- Navigation uses single nouns: “Home”, “Stats”, “Services”, “Projects”, “Contact”.
- The reference page uses emoji as inline glyphs (🎨 📺 🚀 ©); keep them functional, never decorative.

## Color

- Set the page on `page-bg` with body text in `page-text`. The theme is light.
- Identity colours: `color-pow-red`, `color-kapow-yellow`, `color-zoom-blue`, `color-shadow-purple`. Lead with the first; use the rest for accents and emphasis.
- Status colours (`color-success-green`, `color-warning-orange`, `color-info-cyan`) always travel with a word or icon; never signal state by hue alone.
- Each token's note says where the reference page uses it and, for text colours, its contrast on `page-bg`. Keep body text at 4.5:1 or better.

## Typography

- `display` — Bangers, cursive
- `body` — "Comic Neue", cursive

Faces are hosted on Google Fonts (Bangers, Comic Neue); load them with:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bangers&family=Comic+Neue:wght@400;700&display=swap">
```

- Set titles in `display`, sections in `heading-2` and running text in `body`.
- Uppercase is reserved for small labels (`heading-2`, `heading-3`, `label`), always with the letter-spacing given.

## Spacing, shape and elevation

- Spacing steps: `space-xs` 8px, `space-sm` 16px, `space-md` 24px, `space-lg` 32px, `space-xl` 48px, `space-2xl` 64px. Pad cards and sections from these steps only.
- Corners: `radius-full` 50%.
- Elevation: `shadow-comic`, `shadow-hover`, lowest first for resting cards, higher for hover and overlays.

## States and motion

- Hover States:
- Lift effect: translateY(-4px)
- Shadow increase: from 8px to 12px offset
- Color intensification (10% darker)
- Border thickens slightly (4px to 5px)

- Click/Active States:
- Push down: translateY(2px)
- Shadow decrease to 4px
- Scale: 0.98
- Brief flash of accent color

- Loading States:
- Halftone pattern animation (rotating)
- "LOADING..." text in Bangers font
- Color pulse effect
- Progress shown in speech bubble

- Transitions:
- Fast actions: 0.15s cubic-bezier (snappy)
- Standard: 0.25s ease-out
- Slow reveals: 0.4s ease-in-out
- All disabled if prefers-reduced-motion
